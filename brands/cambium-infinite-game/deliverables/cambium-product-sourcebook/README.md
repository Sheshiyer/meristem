# Cambium Product Sourcebook

This is a manifest-based delivery packet for the Cambium Infinite Game Engine concept.

It deliberately keeps one canonical copy of every binary and document. `MANIFEST.json` points to the authored product sources, generated visual assets, and downloaded NotebookLM artifacts in the parent brand directory. Verify a file against the recorded SHA-256 digest before using it.

## Contents

- Five product-only source documents.
- Twelve Codex-generated visual assets with explicit origin and proof labels.
- A local-only process/provenance packet that is excluded from the product notebook.
- NotebookLM synthesis artifacts when their remote generation is complete.
- A Cambium genesis contract payload and evidence receipt.

## Claims boundary

The package defines a product concept, brand system, operating doctrine, and conceptual visual language. It does not prove a live autonomous operator, public release, manufactured product, measured customer outcome, or approved paid campaign.
