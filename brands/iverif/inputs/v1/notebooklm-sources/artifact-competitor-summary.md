# Competitor Summary

> Competitive landscape, standout gaps, and differentiation context.

**Brand:** iverif.io

**Kickstarter Section:** Part 1 — Understanding the Market

**Source Skill:** `competitor-analysis`

## Competitor Analysis

### Market Gaps

- No existing tool built specifically for EU energy subsidy document validation
- Generic OCR tools cannot handle cross-document consistency checking
- Legacy document management lacks programme-specific rule engines
- Self-serve SaaS requires operators to configure complex validation rules alone
- Single-market tools (e.g., French CEE-only) cannot serve multi-country operators

### Technical Benchmark


#### Dimensions

- **Processing Speed:** 30 seconds per full dossier
- **Document Types:** Unlimited — invoices, attestations, certificates, technical sheets, affidavits
- **Programme Coverage:** 6 pre-configured EU programmes + custom configurations
- **Accuracy Target:** <2% rejection rate

- **Materials:**
  - Generative AI for structured data extraction
  - Cross-document reasoning engine
  - Configurable rule engine per programme
  - EU-hosted infrastructure (GDPR compliant)
  - Full API for CRM/integration

### Verified Anxieties

- Will AI catch edge cases that manual review catches?
- What happens when programme rules change?
- Is my data secure and GDPR compliant?
- How long does onboarding actually take?
- Will this integrate with our existing workflow?

### Competitive Landscape

- **Direct Competitors:**
  - **Name:** Generic OCR Tools | **Weakness:** No cross-document validation, no programme rules
  - **Name:** Legacy DMS (SharePoint, DocuSign) | **Weakness:** No AI extraction, no validation logic
  - **Name:** Single-market CEE Tools | **Weakness:** France-only, not configurable for other programmes
- **Differentiation:**
  - Only platform with managed onboarding — real team configures your rules
  - Only platform pre-configured for 6 EU programmes
  - Only platform with generative AI cross-document reasoning
  - Go-live in 5-7 days vs. months
