# Identité de marque iverif

iverif est la validation documentaire AI pour opérateurs de subventions énergétiques. Essence : un **signal de validation avant dépôt**. Personnalité sage + architecte — précise, autoritaire, sobrement confiante, sans hype. GTM France : région FR / fr-FR ; domaines iverif.fr et iverif.io. Références craft Stripe, Notion, Vercel, Linear = aspirationales. Actifs fournis (logo-icon, og-image, screenshot-hero) listés au manifest ; pas de régénération campaign aveugle.
