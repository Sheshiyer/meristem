# Stratégie produit iverif

L’acheteuse primaire Marie Durand pilote le back-office dossiers CEE chez un délégataire / opérateur mid-market FR. iverif se différencie comme logiciel de validation contre règles programme — pas une distribution de primes type Hellio/Effy, pas un OCR générique, pas un DMS de stockage. Contexte concurrent nommé : Hellio, Effy, Économie d'Énergie SAS, GEO PLC (observation). Les % d’outcome et SLA de go-live restent bloqués sans reçus datés.
