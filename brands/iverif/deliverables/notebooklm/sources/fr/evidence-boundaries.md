# Frontières de preuve

Faits publics : dispositif CEE, fiches d’opérations standardisées, rôles obligé/délégataire. Faits first-party : nommage, intention de programmes, actifs, verrouillage de voix. Interdit : garanties de taux de rejet, affiliation, montants euros concurrents, tailles de marché non sourcées, endorsement PNCEE.
