# Campaign learning

## Purpose

Capture prioritization signals for FR GTM (LinkedIn FR, JDN, Les Échos, WTTJ, PNCEE context). These signals guide iteration; they are **not** customer-facing proof.

## Allowed internal uses

- Rank hooks / creatives for further tests
- Refine Marie Durand title targeting
- Note which explanations of obligé vs délégataire reduce confusion
- Flag copy that tripped claim review

## Forbidden conversions

- Reply rates → “customers love iverif”
- Impressions → market leadership
- Draft Explee creatives → live performance claims
- Channel-plan rows → budget authority

## Tag

All orchestrated learning logs should carry `gtm_tag: FR GTM`.
