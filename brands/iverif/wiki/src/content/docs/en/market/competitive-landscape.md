# Competitive landscape

**Frame:** Named actors below are mostly **market operators / primes distributors**, not proof they ship equivalent AI cross-document validation software. Tooling substitutes are a second frame.

## Named FR / EU context (observation)

| Name | Class | Differentiation rule |
| --- | --- | --- |
| **Hellio** | FR CEE / primes accompaniment (C1) | iverif validates dossiers; Hellio operates CEE / primes services. No affiliation. |
| **Effy** | Renovation + Prime Effy under CEE (C2) | Effy sells primes/journeys; iverif sells pre-submission document validation. Never reuse euro amounts. |
| **Économie d'Énergie SAS** | FR energy-savings / CEE market actor (C3) | Operator/market participant — not AI dossier-validation software. Feature matrix pending primary-page fetch. |
| **GEO PLC** | EU obligation-scheme participant (C3) | Soft differentiation: software validation vs scheme operator. No invented feature parity. |

## Indirect tooling substitutes

- **Generic OCR / IDP** — extraction without embedded CEE programme rules
- **Legacy DMS** (SharePoint, DocuSign, etc.) — store and route; do not validate against fiches
- **Single-market CEE point tools** — limited multi-programme coverage / self-serve rule burden

## Market gap (hypothesis)

Few tools are explicitly positioned as **pre-submission AI validation for CEE / délégataire back-offices**. Treat as a working category hypothesis — not a monopoly claim.

## Buyer confusion to clear

Operators shopping Hellio/Effy-style journeys may confuse **primes distribution** with **validation software**. Messaging must separate the two.
