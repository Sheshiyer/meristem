# Claims and evidence boundaries

## Supported (ledger `fact` / first-party)

| Claim class | Safe language |
| --- | --- |
| fact F1 | Brand name iverif; domains iverif.fr (brand) and iverif.io (wiki); GTM region FR / fr-FR. |
| fact F2 | Programme scope **intent** includes CEE, Primes Énergie, Conto Termico, BEG, ECO4, MOVES III. |
| fact F3 | User assets exist: logo-icon, og-image, screenshot-hero. |
| fact F4 | Voice: precise / authoritative / no-hype; craft refs are aspirational, not partnerships. |
| fact P1–P3 | CEE is a statutory FR obligation scheme with standardised opérations / fiches (cite ministry / Service-Public; re-fetch before live publish). |
| fact P4–P5 | “Prime énergie” is the consumer-facing CEE aid label; market roles include obligé, délégataire, beneficiary. |

## Observation only (not iverif proof)

Named FR/EU market peers — **Hellio**, **Effy**, **Économie d'Énergie SAS**, **GEO PLC** — and tooling substitutes (generic OCR, legacy DMS). Use for differentiation framing only (ledger C1–C4).

## Hypotheses (label explicitly)

1. FR operators respond better to CEE / Primes accuracy + audit trails than to multi-country breadth first.
2. Clear obligé vs délégataire language reduces mistrust.
3. Differentiation vs Hellio/Effy works when iverif is framed as pre-submission validation software.

## BLOCKED — prohibited until proved

> **Do not publish** without a dated iverif-specific evidence receipt:

- Specific rejection-rate reduction, “up to 90% fewer errors”, “30 seconds per dossier”, “go-live in 5–7 days”
- Claim that iverif is an accredited **obligé**, **délégataire**, or government-affiliated body
- Reuse of competitor euro primes amounts, Trustpilot scores, or “jusqu’à X% d’aides”
- Market-size figures (~2M CEE ops/year, 15–20% rejection) until backed by a dated primary source in the ledger
- Privacy / GDPR / “EU-hosted” assurances beyond an audited implementation receipt
- PNCEE partnership or endorsement
