# Séquences email

Les séquences bilingues sont dans les outputs wave (`launch-email-sequence`, `prelaunch-email-sequence`, `welcome-email-sequence`). `defaultLocale: fr` pour le GTM France.

## Thèmes

1. Reconnaissance du problème — erreurs documentaires évitables
2. Éducation de catégorie — logiciel de validation ≠ marketplace de primes
3. Parcours produit — règles, contrôles, piste d’audit
4. Confiance — discipline de voix ; pas de métriques bloquées
5. CTA — démo / échange sur iverif.fr

## Conformité

Chaque ligne claim-bearing doit mapper un `fact` du ledger ou être étiquetée hypothèse.
