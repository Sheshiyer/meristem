# Claims et frontières de preuve

## Autorisé (ledger `fact` / first-party)

| Classe | Langage sûr |
| --- | --- |
| fact F1 | Marque iverif ; domaines iverif.fr (marque) et iverif.io (wiki) ; région GTM FR / fr-FR. |
| fact F2 | Intention de programmes : CEE, Primes Énergie, Conto Termico, BEG, ECO4, MOVES III. |
| fact F3 | Actifs utilisateur présents : logo-icon, og-image, screenshot-hero. |
| fact F4 | Voix : précise / autoritaire / sans hype ; références craft aspirationales, pas des partenariats. |
| fact P1–P3 | Les CEE sont un dispositif d’obligation FR avec opérations standardisées / fiches (citer ministère / Service-Public ; re-fetch avant publication live). |
| fact P4–P5 | « Prime énergie » est le libellé grand public de l’aide CEE ; rôles marché : obligé, délégataire, bénéficiaire. |

## Observation seule (pas une preuve iverif)

Pairs nommés — **Hellio**, **Effy**, **Économie d'Énergie SAS**, **GEO PLC** — et substituts outillage (OCR générique, DMS legacy). Cadre de différenciation uniquement (ledger C1–C4).

## Hypothèses (à étiqueter)

1. Les opérateurs FR répondent mieux à l’exactitude CEE / Primes + pistes d’audit qu’à la largeur multi-pays d’abord.
2. Un langage clair obligé vs délégataire réduit la méfiance.
3. La différenciation vs Hellio/Effy fonctionne quand iverif est cadré comme logiciel de validation pré-dépôt.

## BLOQUÉ — interdit jusqu’à preuve

> **Ne pas publier** sans reçu daté spécifique iverif :

- Réduction chiffrée du taux de rejet, « jusqu’à 90 % d’erreurs en moins », « 30 secondes par dossier », « go-live en 5–7 jours »
- Affirmer qu’iverif est un **obligé**, un **délégataire** accrédité, ou un organisme affilié à l’État
- Réutiliser montants euros concurrents, scores Trustpilot, ou « jusqu’à X % d’aides »
- Tailles de marché (~2 M d’opérations CEE/an, 15–20 % de rejet) sans source primaire datée dans le ledger
- Assurances privacy / RGPD / « hébergé UE » sans reçu d’implémentation audité
- Partenariat ou endorsement PNCEE
